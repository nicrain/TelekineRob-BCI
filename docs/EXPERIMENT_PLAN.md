## 0. 系统控制模型（已确认，2026-08-12）

**双人协同控制，两台 EEG 设备，一人一台：**

| 操作者 | 注意力 → | 眨眼 → |
|---|---|---|
| **A** | 前进 / 停止 | — |
| **B** | 转向（转 / 不转） | **切换方向（左转 ↔ 右转）** |

- 注意力是主控制模态（指标 tbr/ei/alpha，各自设备独立校准）；眨眼是 B 的离散方向开关。
- 眨眼检测**已接通运行管线**（`eeg_control_node.py` 基于指标确认眨眼 → 翻转 `steer_direction` 1=右/-1=左）。

## 1. 实验设计（做什么）

### 1.0 实验因素（自变量，2026-08-12 确认）

| 因素 | 水平 | 说明 |
|---|---|---|
| **指标** | alpha / tbr / ei | **三个都测**，每个单独做控制实验，比较哪个指标控制质量最好 |
| **设备模式** | 单设备 / 双设备 | 单设备 = 同一操作者/设备，**前进和转向分块各测**；双设备 = 两人分工 |
| **电极（仅 hybrid）** | 干 / 湿 | HybridBlack 干电极 vs 湿电极分别测，比较信号/控制质量 |

> ⚠️ 多因素设计的代价：3 指标 × 2 模式 × 2 电极 = 很多组合，**trial 总量和疲劳是现实约束**。建议：指标按 session 或分块切换（每块校准一次）；干湿/单双作为被试内对照条件，顺序随机平衡。M2 层面宁可每格 trial 精不要面面俱到。

### 1.1 总体结构（两层）

| 层 | 被试 | 目标 |
|---|---|---|
| **预实验 Pilot** | 开发者本人 | 系统全链路可用 + 记录闭环成立（两个通道校准合理、眨眼能稳定切换方向、机器人有响应、数据能落盘） |
| **正式实验** | 5–10 对/名被试（两人一组协同） | 出有效数据；每对被试 1–3 次 session（建议 ≥2，至少能报告性能跨 session 稳定，防"单次运气"质疑） |

### 1.2 任务范式（分通道验证 + 联合任务）

**① 注意力通道验证（A：前进/停止）**
- 两种 trial：**注意**（做心算等集中注意力）vs **休息**（放松）
- 注意 trial 期望小车前进、休息 trial 期望停住
- 每状态 ≥20 trial，记命中率/虚警率

**② 注意力通道验证（B：转向）**
- 同样注意 vs 休息 → 期望"开始转 / 不转"
- 独立于 A 验证，证明 B 的注意力通道也能驱动转向

**③ 眨眼方向开关验证（B：左/右）**
- 提示"切换到 左转/右转"→ 期望一次（或几次）眨眼完成切换
- 记**方向切换正确性**（P44②）：目标方向改变时输出是否切到新目标（dir_hit）、目标稳定时输出是否仍切换（dir_fa）；**rest 自然眨眼 ≠ 误触发**（relax 是自由动作，不计入）
- **眨眼检测为瞬态判据**（P44③）：相对近期基线判尖峰，持续 rest 漂移不触发；眨眼确认/保持期间转向钳中性 0.5，不冻结旧转向值

**④ 联合任务（旗舰，双人协同）**
- A 控前进/停、B 控转向+方向，两人一起把 Thymio 开到目标点
- 记完成率、完成时间、路径效率、两人配合的失误点

### 1.3 对照条件（证明不是碰运气/别的因素）

- **EEG vs 随机水平（chance）**：随机打乱标签算 chance，证明各通道显著高于随机（注意通道 50%；眨眼切换按实际误触率基准）。
- **单设备 vs 双设备（技术可行性，不是"谁更优"）**：单设备 = 同一操作者/设备，**前进和转向分开各测**，证明单设备两种控制都可用；双设备 = 两人并行，前进/转向**同时跑不冲突**，证明双人协同技术成立。参与度/趣味性差异是博士的指标，不在此对比。
- **指标对比**：alpha / tbr / ei 各做一轮，比控制质量（哪个指标最好用）。
- **干/湿电极对比（hybrid）**：同协议分别用干、湿电极跑，比信号/控制质量。

### 1.4 被试与流程

- 记录元数据：年龄、性别、利手、BCI 经验、疲劳/状态自评；双人组记录配对与各自角色。
- 每次 session：各自校准（采集基线）→ 熟悉练习（不计入正式）→ 正式 trial → prompt 间隔 → 再一轮。（P43：trial 之间只有一个倒计时——可配置 prompt，无独立休息/间隔阶段。）
- **电极（hybrid）**：干/湿电极配置在 session 前设定，记录用的是哪种；同一被试干湿各跑一轮以对比。
- 条件顺序**随机/平衡**（防顺序效应）。

### 1.5 次数与随机化

- 每通道每状态 trial ≥20（统计力），trial 间 prompt 间隔（P43：唯一倒计时，可配置），目标顺序随机化。
- 方法学写清楚：被试对数、session 数、每通道 trial 数、间隔、随机化方案。

## 2. 要记录的数据

| # | 类别 | 明细 |
|---|---|---|
| 1 | **原始 EEG** | 两台设备各：通道数、采样率、raw 值、**LSL 时间戳**（两台可对齐）；存原始数据不存特征（事后可重算） |
| 2 | **特征/指标** | 每 epoch 的 **tbr / ei / alpha**（两台各自）；计算时间窗、步长、通道 |
| 3 | **校准数据** | 每台设备校准的每样本、每指标阈值/min-max；每 session 校准一遍（跨 session 阈值变化本身是分析点） |
| 4 | **标签/真值（最关键）** | 每 trial：A 目标状态（注意/休息）、B 目标状态（注意/休息）、B 目标方向（左/右）+ trial 起止时间戳。⚠️ 现系统大概率**未记录**——见 §4 待补 |
| 5 | **系统输出** | A 实际速度、B 实际转向值、眨眼触发/切换事件（含时间戳）、每次指标的"决策"与置信度；发送的 cmd_vel 序列；机器人行为/位置/成败（能记录则记） |
| 6 | **时序/同步** | 系统各环节时间戳：EEG 采到 → 特征算完 → 分类 → cmd_vel 发布（管线延迟，必记）；cmd_vel → 电机响应（可选，需 Thymio 报轮速/外部传感）；LSL 时钟统一 |
| 7 | **元数据** | 被试/角色信息、session 号、条件名（EEG/键盘）、日期；异常标注（掉线/干扰） |

## 3. 分析指标

| # | 类别 | 指标 |
|---|---|---|
| 1 | **注意力通道 A（前进/停）** | 命中率、虚警率、**d′ / AUC**（注意 vs 休息分离度）、注意强度与速度的连续相关 |
| 2 | **注意力通道 B（转向）** | 同样的命中/虚警/d′/AUC（独立验证 B 通道） |
| 3 | **眨眼方向开关** | 眨眼命中率、**误触发率** |
| 4 | **系统延迟** | **管线延迟（EEG→cmd_vel）必测**：注入合成信号（`lsl_test/dummy_dual_streams.py`）或 E1 各环节时间戳相减；**电机响应（cmd_vel→轮子动）可选**：需 Thymio 报轮速或外部传感 |
| 5 | **特征/校准质量** | tbr/ei/alpha 判别力（d′/AUC）、哪指标/通道贡献最大、阈值跨 session 稳定性 |
| 6 | **联合任务** | 导航完成率、完成时间、路径效率（实际走距/最短距）、失误归属（哪个通道/操作者） |
| 7 | **统计** | 被试内配对 t / 被试间均值·SD·CI·ANOVA（条件×通道） |
| 8 | **伪影/可靠性** | 污染 trial（眨眼误触发/肌电/断连）比例、剔除率、剔除前后对比 |
